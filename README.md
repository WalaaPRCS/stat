# لوحة مؤشرات الهلال الأحمر الفلسطيني – قطاع غزة

نسخة مستقلة للسيرفر، تعمل بـ Node.js 24 وSQLite. لا تحتاج Supabase أو حساب ChatGPT. يحتوي المستودع العام على الكود والتعريفات فقط، ولا يحتوي إحصائيات العمل أو كلمات مرور أو قاعدة بيانات.

## النشر على Coolify / panel.infinite.ps

1. New Resource → Public Repository، وأدخل `https://github.com/WalaaPRCS/stat` والفرع `main`.
2. اختر **Docker Compose** وملف `/docker-compose.yml`.
3. أضف متغيري البيئة:
   - `APP_ORIGIN`: رابط التطبيق النهائي مع HTTPS، بدون شرطة مائلة أخيرة، مثل `https://stat.example.org`.
   - `SETUP_KEY`: مفتاح عشوائي خاص. يمكن إنشاؤه على السيرفر: `openssl rand -hex 32`. لا تنشره في GitHub.
4. في إعدادات خدمة `statistics`، عيّن دومين التطبيق والمنفذ الداخلي **3000**. لا حاجة لحجز منفذ 8000 على السيرفر.
5. Deploy، ثم افتح رابط التطبيق واختر «تهيئة المدير». أدخل مفتاح التهيئة والاسم واسم المستخدم وكلمة المرور (12 حرفًا على الأقل). تنغلق شاشة التهيئة تلقائيًا بعد إنشاء أول مدير.
6. من «المستخدمون والصلاحيات» أضف مراكز الإسعاف ثم الحسابات. اربط مدخل البيانات بقسم واحد ومنشأة واحدة. المدير يستطيع إضافة مدير آخر وتعطيل حسابات الموظفين وإعادة تعيين كلمات المرور.

## التخزين والنسخ الاحتياطي

SQLite محفوظة في `/app/storage/statistics.sqlite` داخل volume دائم `statistics_data`. لا تحذف الـvolume عند إعادة النشر. الملفات `-wal` و`-shm` جزء من قاعدة بيانات نشطة؛ أنشئ نسخة SQLite متسقة بدل نسخ الملف منفردًا أثناء العمل. حسابات المستخدمين والجلسات محفوظة أيضًا في قاعدة البيانات، وكلمات المرور مخزنة بمشتقات scrypt مع salt عشوائي.

## الإحصائيات السابقة

قاعدة بيانات Sites لا تنتقل تلقائيًا. يبدأ السيرفر بقاعدة إحصائيات وتعريفات مرافق فارغة. انقل الإحصائيات بشكل خاص بعد التشغيل الأول، قبل بدء الإدخال:

- جهّز JSON خاصًا به الأقسام `hospital`, `phc`, `ems`، وفي كل قسم `records`، وفي الرعاية الأولية `clinics` أيضًا، وفي المستشفيات `hospitals`. يتوافق مع ملفات الاستيراد السابقة أو سجلات API ذات `values`.
- أوقف خدمة الويب، ضع الملف داخل مساحة التخزين الخاصة، ثم شغّل `node server/import.mjs /app/storage/import.json` باستخدام نفس الـvolume.
- لا ترفع الملف إلى GitHub. يدعم الاستيراد قاعدة إحصائيات فارغة فقط، ويطبّق المعاملة كاملة أو يلغيها.
- بيانات الإسعاف السابقة حسب المحافظات؛ تُحفظ تحت «أرشيف المحافظة» ولا تُنسب إلى مركز فعلي. أنشئ المراكز الفعلية للإدخال الجديد.

## الصلاحيات

- الزائر: قراءة الإحصائيات فقط، بدون حساب. تُحجب الملاحظات الداخلية وحقول المصدر من السجلات العامة.
- مدخل البيانات: يقرأ ويعدل سجلات منشأته في قسمه فقط. تُراجع الصلاحيات في السيرفر ولا تعتمد على إخفاء الأزرار.
- المدير: إدارة كل الأقسام والمستخدمين والمراكز. تعطيل الحساب أو تغيير صلاحياته يلغي جلساته السابقة. لا يمكن تعطيل آخر مدير فعال.

PDF عبر نافذة الطباعة («حفظ بصيغة PDF»)، وExcel بصيغة XLSX. التصدير يتبع فلاتر التقرير.

## التشغيل والاختبار محليًا

```sh
npm run build
SETUP_KEY=your-local-private-key APP_ORIGIN=http://localhost:3000 npm start
npm test
```

لا توجد تبعيات npm خارجية. البناء داخل Docker. الاختبارات تستخدم قاعدة بيانات مؤقتة وتحاكي فصل منشآت المستشفيات والعيادات ومراكز الإسعاف وإلغاء الجلسات وCSRF.
